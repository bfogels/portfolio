# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or accidental
information disclosure. Report it privately to
[inquiries@brianfogelson.com](mailto:inquiries@brianfogelson.com) with the URL,
impact, and reproduction steps.

This repository is a static portfolio rather than a supported library or API.
Security fixes will be applied to the live site and the default branch as
appropriate.
